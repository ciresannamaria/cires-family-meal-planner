# Cires Family Meal Planner

A visual, browser-based family meal planner with a recipe library, weekly planner and shopping list.

## Current prototype

- Three views: Meals, Weekly Planner and Shopping List.
- Recipes store structured ingredient names, quantities, units and optional ingredient groups for future filters.
- Add, edit and delete meals, including photos and preparation instructions.
- Add multiple meal entries to any day and meal period, with portions per entry.
- Shopping list combines ingredients across the selected week and scales quantities by portions.
- Print or save the weekly menu and shopping list as PDF from the browser's print dialog.
- Data is saved in this browser using localStorage. Export/import JSON to move data to another browser or device.

## Run locally

Open `index.html` in a modern browser. No server, login or database is required.

## Data note

Browser storage is local to the browser and device. Clearing browser site data can remove it, so export a JSON backup regularly. Photos are stored in the browser as data URLs; keep images reasonably small.
